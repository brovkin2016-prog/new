АВТОМАТИЗАЦИЯ БЭКАПА И ПЕРЕНОСА СЕССИЙ CLAUDE CODE (Windows)
============================================================

Файлы в этой папке:
  Бэкап сессий Claude.bat    — двойной клик = сделать копию сессий сейчас
  Восстановить сессии.bat    — двойной клик = вернуть сессии из копии (новый ПК)
  claude-backup.ps1          — сам скрипт бэкапа (его настраиваете)
  claude-restore.ps1         — сам скрипт восстановления
  install-autobackup.ps1     — включить автобэкап по расписанию (запустить 1 раз)

БЫСТРЫЙ СТАРТ
-------------
1. Скопируйте всю папку windows-claude-tools к себе, например в
   C:\Users\ВашеИмя\Claude-Tools\
2. (по желанию) откройте claude-backup.ps1 Блокнотом и в строке $Dest укажите,
   куда класть копию. По умолчанию — папка OneDrive (синхронизируется в облако сама).
3. Двойной клик по "Бэкап сессий Claude.bat" — копия готова.
4. Чтобы бэкап шёл сам: ПКМ по install-autobackup.ps1 -> "Выполнить с помощью PowerShell".

ЯРЛЫК НА РАБОЧИЙ СТОЛ
---------------------
ПКМ по "Бэкап сессий Claude.bat" -> Отправить -> Рабочий стол (создать ярлык).

ПЕРЕНОС НА ДРУГОЙ ПК / УЧЁТКУ
----------------------------
На новом ПК: установите Claude Code, войдите (любым аккаунтом), положите рядом эти
файлы, в claude-restore.ps1 укажите $Src = путь к вашей копии, двойной клик по
"Восстановить сессии.bat". Затем в папке проекта: claude --resume

Подробности и расширенный вариант (автосинхрон через junction) — в PDF-инструкции.
