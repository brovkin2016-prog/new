CLAUDE SESSION MANAGER — программа с интерфейсом (Windows)
===========================================================

ГЛАВНОЕ — запуск программы:
  "Запустить программу.vbs"   <-- двойной клик, откроется окно с кнопками
  "Запустить программу.bat"   <-- запасной вариант, если .vbs заблокирован

В окне программы:
  • Папка бэкапа — куда копировать / откуда восстанавливать (кнопка "Обзор…")
  • [Сделать бэкап]          — скопировать все сессии в эту папку
  • [Восстановить сессии]    — вернуть сессии из папки в профиль (новый ПК/учётка)
  • [Папка сессий] / [Папка бэкапа] — открыть в проводнике
  • [Автобэкап: вкл.]        — включить автокопирование (ежедневно 20:00 + при входе)
  • Мои примечания           — ваши личные заметки, сохраняются локально (только у вас)

Путь и примечания сохраняются сами при закрытии (файл claude-session-manager.config.json
рядом с программой).

ЯРЛЫК НА СТОЛ: ПКМ по "Запустить программу.vbs" -> Отправить -> Рабочий стол (создать ярлык).
Можно сменить значок: ПКМ по ярлыку -> Свойства -> Сменить значок.

ПЕРЕНОС НА ДРУГОЙ ПК/УЧЁТКУ:
  1) установить Claude Code и войти (любым аккаунтом — история к аккаунту не привязана);
  2) запустить программу, указать папку с бэкапом, нажать [Восстановить сессии];
  3) в папке проекта выполнить:  claude --resume

Авторизация (~/.claude.json) не переносится — безопасно и для смены аккаунта Claude.
