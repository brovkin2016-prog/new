# Установщик Roblox для Windows 11

1. Скачайте папку `roblox-installer` (оба файла должны лежать рядом).
2. Дважды щёлкните `install-roblox.cmd`.
   - Если Windows SmartScreen предупредит — «Подробнее» → «Выполнить в любом случае».
3. Дождитесь окна установщика Roblox, затем войдите в аккаунт.

Что делает скрипт:
- скачивает официальный `RobloxPlayerInstaller.exe` с roblox.com;
- проверяет цифровую подпись Roblox Corporation (поддельный файл удаляется);
- запускает установку (права администратора не нужны);
- если сайт недоступен — ставит Roblox из Microsoft Store через `winget`;
- если и это не вышло — открывает https://www.roblox.com/download.
